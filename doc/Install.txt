1.Run in cmd：powershell -ExecutionPolicy ByPass -c "$env:UV_INSTALL_DIR = 'D:\UV';irm https://astral.sh/uv/install.ps1 | iex"
2.Use CMD commands to locate the folder that contains the 'pyproject.toml' and 'uv.lock' files.
3.Run in cmd：uv sync
4.Install VS Code or PyCharm, and set the src folder as the project path.
5.Select the Python interpreter at .venv\Scripts\python.exe.
6.Extract 'libs.zip' and copy the 'libs' folder inside it to the same directory as 'pyproject.toml' and 'uv.lock'.
7.Open 'app.py' and start a trial run of the program.
8.Copy all files under examples into the 'P4STemp' folder.
9.Finished!
10.To uninstall, you can directly delete the entire folder (including the virtual environment) where it is located.

For an installation video demonstration, please refer to 'video/install'.
